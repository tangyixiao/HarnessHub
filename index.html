    将活动、Git 记录与使用量关联，具体适配范围见文档。

一处管理，本机运行

Harness Hub registers local Git projects (deduplicated by repository root), detects the Harness installations already on your machine, and starts and manages terminal sessions for them from a single desktop surface.

It does not replace Codex, Claude Code, Gemini CLI or OpenCode, and it does not ship any Harness program or credentials. Session snapshots record what changed during a session without attributing it to AI. Usage from the supported Harness clients is imported through ccusage.

Discovery, history and usage are read from local data — this page shows no live telemetry.
