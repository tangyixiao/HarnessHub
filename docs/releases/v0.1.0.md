# Harness Hub v0.1.0

> **首个正式版本（Windows x64 + Linux x64）。** Downloads: [Release page](https://github.com/tangyixiao/HarnessHub/releases/tag/v0.1.0)。

## What's included（相对 v0.1.0-alpha.5）

- **Git Session Snapshot 全链路**（alpha.5 引入）：会话 start/end 快照 + 窗口摘要
  （`N commits · +X / −Y`），Sessions 页展示；R5 用词纪律（不声称 AI 贡献）。
- **Gemini usage 解析回归**：fixture 形状逐字段取自 ccusage v20.0.24 源码
  （synthetic，待真机数据回填）；opencode 已有真机 fixture 覆盖。
- **Linux 发布流水线**：tag 触发 → ubuntu-22.04 打包（deb + AppImage）→
  安装 + xvfb 隔离冷启动冒烟 → draft release。
- **README 10 分钟上手指南**。
