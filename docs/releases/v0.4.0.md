# Harness Hub v0.4.0

> **Configuration / Profile Plane 版本（ROADMAP E 轨道）。** Downloads: [Release page](https://github.com/tangyixiao/HarnessHub/releases/tag/v0.4.0)。

## What's included（相对 v0.3.0）

- **Provider 配置发现（E14）**：Settings 页只读展示 claude / codex / gemini 的
  当前配置形态；secret 值在 Rust 层 redact（`<redacted>` / set-unset），值不跨 IPC。
- **安全配置投影（E15）**：`~/.claude/settings.json` 的
  read → parse → merge → backup → temp → verify → 原子 rename 管线；
  同名键覆盖、其余内容原样保留、`env` 块深合并；备份留 Hub 目录（最近 10 份）
  - 显式恢复；恢复目标只来自后端自己的备份记录（不接受前端传路径）。
- **凭据登记（E16）**：值进 Secret Store 抽象（FileSecretStore 兜底，0600），
  SQLite 只存句柄（`credential_refs`）；值只在登记这一次跨 IPC，列表/导出永不含值。
- **配置体检（E17）**：`config_doctor` 只读诊断（config 可解析 / 凭据可达含孤儿检测 /
  Provider 指向），只给建议不自动修复。
- **MCP Binding Registry + Harness 同步（E18）**：Hub 侧登记 MCP Server
  （stdio/http，`env_keys` 只存变量名）+ global/harness 绑定；
  「预览差异 → 确认 → 原子同步」进 claude `~/.claude.json` / codex `~/.codex/config.toml`
  （toml_edit 保格式，注释逐字节保留）/ gemini `~/.gemini/settings.json`；
  条目内用户手写的 `env` / `headers` 一律保留；双向导入标记 `imported:<harness>`，
  同名以 Hub（source-of-truth）为准。
- **Prompts Registry + 记忆文件投影（E19）**：canonical markdown 统一登记
  （可绑定项目），按项目 × harness 投影 `CLAUDE.md` / `AGENTS.md` / `GEMINI.md`；
  标记块语义（块外用户内容逐字节保留、重复渲染幂等、begin 未闭合拒绝落盘）；
  Projects 页项目卡内展开区管理（折叠零 IPC）。
- **Skills 只读发现（E19 缩范围）**：扫 `~/.claude/skills/<name>/SKILL.md`
  展示 name / description；坏文件计 skipped 不崩；不做复制投影。
- **System Tray（E19）**：Open Dashboard / 活动会话只读计数 / Quit；
  菜单模型独立纯模块（可单测）；不做 Profile 切换（`ProfileAdapter.activate`
  未实现，切换必须走同一 ProfileAdapter + audit——规划 §4.25）。
- **能力位**：新增 `profiles`（claude）与 `prompts`（claude/codex/gemini），
  均以「实现事实 + 测试回归」为据（ADR-0005 纪律）。
- 其余：v0.3 全部能力（worktree 编排 / 会话回放 / 搜索 / 恢复）。

## Known limitations

- 配置投影 v0.4 仅 claude（codex/gemini 的 JSON/TOML 投影逐个加，各自格式差异大）；
  MCP 同步覆盖 claude/codex/gemini 三家。
- MCP 绑定不做 project scope（`<repo>/.mcp.json` 属用户仓库文件，安全语义单独评审）；
  不做 MCP Runtime 连接（F22）。
- Prompts 不做 harness 级绑定表与全局 prompt 新建入口（全局 = 进所有项目，风险大，
  留后续）；不做记忆文件 → Registry 的双向导入。
- Skills 只读（claude 自身是加载方，复制无消费方）。
- Tray 不做 Profile 切换与 close-to-tray（`ProfileAdapter.activate` 未实现）。
- 真机验收项（标注于 E19 spec）：tray 图标/菜单交互；渲染产物被三个 harness 实际加载。

_纪律不变：以上为本机 / CI 真实输出；未执行项不以「应该可以」表述。_
