# Harness Hub v0.2.0

> **Session Observability 版本（ROADMAP B 轨道）。** Downloads: [Release page](https://github.com/tangyixiao/HarnessHub/releases/tag/v0.2.0)。

## What's included（相对 v0.1.0）

- **只读会话回放（B6）**：Claude Code 转录（`~/.claude/projects/**/*.jsonl`）在
  `/replay` 页只读回放——会话发现列表 + user/assistant 时间线（thinking 标注、
  子代理徽标、skipped 计数脚注）。16 MiB 上限、未知类型计数不崩；**IPC 不接受
  文件系统路径**（sessionId 白名单解析）。claude `replay` capability 翻 true。
- **全文搜索（B7）**：FTS5 **trigram** 索引（中文/英文/混合子串可搜；<3 字符
  显式报错）。索引**默认关闭**、显式重建、按 project_dir 排除、关闭即清空
  （隐私纪律）；(size, mtime) 指纹增量。
- **工具调用与子代理线程（B8）**：消息内工具卡（输入/结果 JSON 摘要，≤2 KiB
  截断并标注）；sidechain 行按 parentUuid 链分段为子代理线程。
- **恢复外部会话（B9）**：回放页「在终端中恢复」→ `claude --resume <id>` 走既有
  终端生命周期（containment、Git 快照、状态机同一条链）；同一外部会话幂等去重。
  claude `resume` capability 翻 true（参数拼接 fixture 锁定；完整续聊验收随
  交互场景）。
- 其余：v0.1 全部能力（项目登记、四 Harness 检测/终端、ccusage usage、
  Git Session Snapshot + 窗口摘要、插件宿主 v0.1、Linux/Windows 安装包）。

## Known limitations

- 回放/搜索/恢复目前仅 Claude Code（唯一 `replay`/`resume` capability 为 true 的
  harness）；其余 harness UI 不渲染入口（ADR-0005 零宣称）。
- claude resume 的完整续聊验收（真实 `--resume` 会话继续对话）待用户交互场景；
  当前证据为参数拼接 fixture + 真机 launch 确认。
- 回放按需现读、不落库：超大转录（接近 16 MiB 上限）打开耗时与文件大小成正比。
- 搜索 <3 字符不支持（trigram 下限），UI 有明确提示。
- 沿用 v0.1.0：Gemini/OpenCode GUI readiness、CodeBuddy detection-only、
  插件宿主 observe-only、Linux 插件需 `python-is-python3`。

_纪律不变：以上为本机 / CI 真实输出；未执行项不以「应该可以」表述。_
