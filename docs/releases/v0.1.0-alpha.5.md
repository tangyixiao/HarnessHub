# Harness Hub v0.1.0-alpha.5

> **Alpha pre-release.** 本版交付 Git Session Snapshot 全链路与 Linux 发布流水线。
> Downloads: [Release page](https://github.com/tangyixiao/HarnessHub/releases/tag/v0.1.0-alpha.5)。

## What's included（相对 v0.1.0-alpha.4）

- **Git Session Snapshot（ROADMAP A1，v0.1 Release Gate 项）**：
  会话启动成功与终态写入后各拍一次有界只读 Git 快照（HEAD、四类文件计数），
  SQLite 持久化（migration 0010），Sessions 页展示「Git · 会话期间的变更」；
  快照 best-effort、后台线程拍摄，不阻塞会话生命周期；文案遵守 R5（不声称 AI 贡献）。
- **31 阶段开发路线图**：`docs/ROADMAP.md`（v0.1 收尾 → Session Observability →
  Worktree/并行 → 更多 Harness → Config/Profile Plane → AI Runtime → Trace/安全 → Runtime/Analytics）。
- **CI 加固**：PR CI 补 `format:check` 门、job 超时、并发取消（PR #20）。
- **Linux 发布流水线**：新增 tag 触发的 release workflow（ubuntu-22.04，
  deb + AppImage，资产去空格 + SHA256SUMS，draft pre-release）（PR #21）。
  本 release 的 Linux 资产即由该流水线首次真实运行产出。
- **Linux CI 调研文档**：`docs/plans/2026-10-24-linux-packaging-ci.md`
  （含 22.04 退役倒计时与插件宿主 `python`/`python3` 风险记录）。

## Installation

- **Linux x64**：`Harness-Hub_0.1.0-alpha.5_amd64.deb`（主交付）或
  `Harness-Hub_0.1.0-alpha.5_amd64.AppImage`（免安装）。SHA-256 见 `SHA256SUMS`。
- **Windows x64**：NSIS 安装包（本地构建，流程同 alpha.4），unsigned。

Harness Hub 不捆绑 Codex / Claude Code / Gemini CLI / OpenCode / CodeBuddy 或其凭据；
请自行安装并认证各 Harness。Usage 数据导入仍走 ccusage（PATH / 用户配置 / 托管 npx 兜底）。

## Known limitations

- 沿用 alpha.4：Gemini CLI 认证被测机拒绝、GUI TUI 渲染依赖环境（readiness 边界）；
  OpenCode GUI 渲染受跨 Harness 环境问题阻塞；CodeBuddy 仅 detection；
  插件宿主 v0.1 无 UI、权限 observe-only。
- Git 快照只描述「会话期间的变更」，不能证明代码由 AI 编写；
  没有快照不代表没有变化（best-effort）。
- Linux 打包基座为 ubuntu-22.04（glibc 2.35）；该镜像已进入 GitHub 弃用流程，
  后续需迁移容器构建或宣布 24.04 基线。
- Linux 上插件宿主 spawn `python`，Debian/Ubuntu 默认无此命令（只有 `python3`），
  插件功能在 Linux 开箱不可用（修复排在路线图后续）。
