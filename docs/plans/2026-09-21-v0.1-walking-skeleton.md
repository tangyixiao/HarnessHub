## Global Constraints

以下约束对**每个 Task** 都成立，不再逐条重复：

1. **Local-first**：原始 Prompt / Response / Code / Session 数据默认不上传；网络能力必须显式、可关闭、可解释；估算值必须标记 `estimated`。
2. **外部 Harness 数据只读**：只读取其目录与日志，绝不写入、绝不修改。
3. **迁移只增不改**：schema 变更必须新增 `src-tauri/src/db/migrations/NNNN_*.sql`，禁止修改已提交的 migration。
4. **幂等由数据库唯一约束保证**：`usage_events.dedupe_key` 唯一、`sessions(harness_id, source_session_id)` 部分唯一。应用层不得用「先查再插」代替约束。
5. **`runtime_target_id` 必填**：所有 Session 都必须关联运行目标；v0.1 只有 `local`（ADR-0021）。
6. **分层**：领域模块（db / harness / usage / session / pty / …）不得依赖 Tauri GUI 类型；只有 `commands.rs` 与 `lib.rs::run()` 接触 Tauri。
7. **前端 IPC 单入口**：`src/features/*` 组件禁止直接 `invoke()`，必须走 `src/lib/ipc.ts`。
8. **未验证不宣称**：能力矩阵里为 `true` 的项必须有对应测试或验收记录；否则保持 `false`，并把理由写进代码注释。
9. **提交前全绿**：`pnpm verify` 与 `pnpm python:test` 必须通过，提交信息用 `feat:` / `fix:` / `test:` / `docs:` 前缀，一次提交只做一件事。
10. **TDD**：先写失败测试 → 确认失败 → 最小实现 → 确认通过 → 重构 → 提交。

```rust
//! 外部 Harness 的二进制与版本探测。
//!
//! Windows 现实（本机实测）：npm 全局安装的 Harness 是 **shim 三件套** ——
//! `codex`（POSIX bash 脚本）、`codex.cmd`、`codex.ps1` 并存，而 `PATHEXT` **不含 `.PS1`**。
//!
//! 两条硬规则：
//!   1. 无扩展名的 `codex` 是 shell 脚本，Windows **无法** CreateProcess，只能作最后兜底。
//!      （真机踩过：优先返回它导致 `--version` 永远读不出来。）
//!   2. 必须显式覆盖 `.ps1`，否则「只有 ps1 的机器」会被误判为未安装。

use std::collections::HashSet;
use std::path::{Path, PathBuf};
use std::process::Command;

use crate::error::Result;

#[cfg(windows)]
const EXECUTABLE_EXTENSIONS: &[&str] = &["cmd", "exe", "bat", "com", "ps1"];

#[cfg(not(windows))]
const EXECUTABLE_EXTENSIONS: &[&str] = &[];

/// 给定目录下的候选可执行路径，顺序即优先级。
///
/// Windows：先枚举真实可执行扩展名，无扩展名只作最后兜底。
/// 其他平台：无扩展名优先。
pub fn candidate_paths(dir: &Path, name: &str) -> Vec<PathBuf> {
    let mut candidates: Vec<PathBuf> = EXECUTABLE_EXTENSIONS
        .iter()
        .map(|extension| dir.join(format!("{name}.{extension}")))
        .collect();

    candidates.push(dir.join(name));
    candidates
}

/// 从 `--version` 输出中抽取第一个形如 `1.2` / `1.2.3` 的 token。
pub fn parse_version(raw: &str) -> Option<String> {
    raw.split_whitespace()
        .map(|token| token.trim_start_matches('v'))
        .find(|token| {
            let mut parts = token.split('.');
            match (parts.next(), parts.next()) {
                (Some(major), Some(minor)) => {
                    !major.is_empty()
                        && !minor.is_empty()
                        && major.chars().all(|c| c.is_ascii_digit())
                        && minor.chars().all(|c| c.is_ascii_digit())
                }
                _ => false,
            }
        })
        .map(str::to_string)
}

/// 探测外部 Harness 所需的宿主能力。
///
/// 抽成 trait 是为了让检测逻辑可以脱离真实文件系统与真实进程测试。
pub trait HostProbe: Send + Sync {
    fn find_executable(&self, name: &str) -> Option<PathBuf>;
    fn read_version(&self, executable: &Path) -> Result<Option<String>>;
    fn dir_exists(&self, path: &Path) -> bool;
    fn home_dir(&self) -> Option<PathBuf>;
}

/// 真实宿主实现。
pub struct SystemHostProbe;

impl SystemHostProbe {
    pub fn new() -> Self {
        Self
    }

    fn path_entries() -> Vec<PathBuf> {
        std::env::var_os("PATH")
            .map(|value| std::env::split_paths(&value).collect())
            .unwrap_or_default()
    }
}

impl Default for SystemHostProbe {
    fn default() -> Self {
        Self::new()
    }
}

impl HostProbe for SystemHostProbe {
    fn find_executable(&self, name: &str) -> Option<PathBuf> {
        let mut seen = HashSet::new();
        for dir in Self::path_entries() {
            if !seen.insert(dir.clone()) {
                continue;
            }
            for candidate in candidate_paths(&dir, name) {
                if candidate.is_file() {
                    return Some(candidate);
                }
            }
        }
        None
    }

    fn read_version(&self, executable: &Path) -> Result<Option<String>> {
        let output = Command::new(executable).arg("--version").output()?;
        if !output.status.success() {
            return Ok(None);
        }
        let stdout = String::from_utf8_lossy(&output.stdout);
        Ok(parse_version(&stdout))
    }

    fn dir_exists(&self, path: &Path) -> bool {
        path.is_dir()
    }

    fn home_dir(&self) -> Option<PathBuf> {
        std::env::var_os("USERPROFILE")
            .or_else(|| std::env::var_os("HOME"))
            .map(PathBuf::from)
    }
}
```

```rust
//! Codex CLI 适配器。
//!
//! 只实现「检测 + 能力声明 + 启动」中的检测与能力；日志解析属于 `usage`（ADR-0002）。

use std::path::{Path, PathBuf};
use std::sync::Arc;

use crate::error::{Error, Result};
use crate::harness::adapter::{
    DetectResult, HarnessAdapter, HarnessCapabilities, HarnessId, LaunchRequest, ProcessHandle,
    ResumeRequest,
};
use crate::harness::probe::HostProbe;

pub const CODEX_ID: &str = "codex";
const EXECUTABLE_NAME: &str = "codex";

/// Codex 的数据目录候选：Windows 与 Linux 一致，都是 `~/.codex`。
pub fn codex_data_dir_candidates(home: &Path) -> Vec<PathBuf> {
    vec![home.join(".codex")]
}

pub struct CodexAdapter {
    probe: Arc<dyn HostProbe>,
}

impl CodexAdapter {
    pub fn new(probe: Arc<dyn HostProbe>) -> Self {
        Self { probe }
    }

    fn existing_data_dirs(&self) -> Vec<String> {
        let Some(home) = self.probe.home_dir() else {
            return Vec::new();
        };
        codex_data_dir_candidates(&home)
            .into_iter()
            .filter(|path| self.probe.dir_exists(path))
            .map(|path| path.to_string_lossy().into_owned())
            .collect()
    }
}

impl HarnessAdapter for CodexAdapter {
    fn id(&self) -> HarnessId {
        HarnessId::from(CODEX_ID)
    }

    fn detect(&self) -> DetectResult {
        let binary = self.probe.find_executable(EXECUTABLE_NAME);
        let version = binary
            .as_deref()
            .and_then(|path| self.probe.read_version(path).ok().flatten());

        DetectResult {
            installed: binary.is_some(),
            binary_path: binary.map(|path| path.to_string_lossy().into_owned()),
            version,
            data_paths: self.existing_data_dirs(),
        }
    }

    fn version(&self) -> Result<Option<String>> {
        match self.probe.find_executable(EXECUTABLE_NAME) {
            Some(path) => self.probe.read_version(&path),
            None => Ok(None),
        }
    }

    /// **全部为 `false`**，这是当前唯一诚实的取值。
    ///
    /// Global Constraint #8 / ADR-0022：能力为 `true` 必须有测试或验收记录支撑。
    /// PTY（Task 4）与 ccusage（Task 5）都还没落地，因此 launch / terminal / resume /
    /// usage 一律不得宣称支持。每实现一项，就在对应 Task 验收通过后单独置 `true`，
    /// 不要提前把整组打开。
    fn capabilities(&self) -> HarnessCapabilities {
        HarnessCapabilities::default()
    }

    fn launch(&self, _request: LaunchRequest) -> Result<ProcessHandle> {
        Err(Error::InvalidInput(
            "Codex 尚未接入 PTY 启动（见 docs/plans Task 4）".to_string(),
        ))
    }

    fn resume(&self, _request: ResumeRequest) -> Result<ProcessHandle> {
        Err(Error::InvalidInput(
            "Codex resume 尚未接入（见 docs/plans Task 4）".to_string(),
        ))
    }
}
```

```ts
  launch: boolean;
  terminal: boolean;
  resume: boolean;
  usage: boolean;
  replay: boolean;

  subagents: boolean;
  liveState: boolean;

  id: string;
  displayName: string;
  installed: boolean;
  binaryPath: string | null;
  version: string | null;
  capabilities: HarnessCapabilities;
  dataPaths: string[];
};

export function normalizeHarnessSummary(raw: unknown): HarnessSummary | null {
  if (typeof raw !== 'object' || raw === null) return null;
  const source = raw as Record<string, unknown>;
  const id = typeof source.id === 'string' ? source.id.trim() : '';
  if (id.length === 0) return null;

  return {
    id,
    displayName:
      typeof source.displayName === 'string' && source.displayName.length > 0
        ? source.displayName
        : id,
    installed: source.installed === true,
    binaryPath: typeof source.binaryPath === 'string' ? source.binaryPath : null,
    version: typeof source.version === 'string' ? source.version : null,
    capabilities: normalizeCapabilities(source.capabilities), // 只有 === true 才算支持
    dataPaths: Array.isArray(source.dataPaths)
      ? source.dataPaths.filter((path): path is string => typeof path === 'string')
      : [],
  };
}

export async function listHarnesses(): Promise<IpcResult<HarnessSummary[]>> {
  const result = await invokeCommand<unknown>('list_harnesses');
  if (!result.ok) return result;

  const summaries = Array.isArray(result.data)
    ? result.data
        .map(normalizeHarnessSummary)
        .filter((summary): summary is HarnessSummary => summary !== null)
    : [];

  return { ok: true, data: summaries };
}
```

```rust
//! 极小的 RFC3339 UTC 时间格式化。
//!
//! 刻意不引入时间库：v0.1 只需要「当前时刻 → RFC3339 字符串」，
//! 而 SQLite 侧的时间由 `strftime` 负责。

use std::time::{SystemTime, UNIX_EPOCH};

/// Unix 秒 → `YYYY-MM-DDTHH:MM:SSZ`。
pub fn format_rfc3339(unix_seconds: u64) -> String {
    let days = (unix_seconds / 86_400) as i64;
    let seconds_of_day = unix_seconds % 86_400;
    let (year, month, day) = civil_from_days(days);

    format!(
        "{year:04}-{month:02}-{day:02}T{:02}:{:02}:{:02}Z",
        seconds_of_day / 3_600,
        (seconds_of_day % 3_600) / 60,
        seconds_of_day % 60
    )
}

/// 当前时刻（UTC）。
pub fn now_rfc3339() -> String {
    let seconds = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|duration| duration.as_secs())
        .unwrap_or(0);
    format_rfc3339(seconds)
}

/// Howard Hinnant `civil_from_days`：1970-01-01 起的天数 → (年, 月, 日)。
fn civil_from_days(days: i64) -> (i64, u32, u32) {
    let z = days + 719_468;
    let era = if z >= 0 { z } else { z - 146_096 } / 146_097;
    let doe = (z - era * 146_097) as u64;
    let yoe = (doe - doe / 1_460 + doe / 36_524 - doe / 146_096) / 365;
    let year = yoe as i64 + era * 400;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    let mp = (5 * doy + 2) / 153;
    let day = (doy - (153 * mp + 2) / 5 + 1) as u32;
    let month = if mp < 10 { mp + 3 } else { mp - 9 } as u32;

    (if month <= 2 { year + 1 } else { year }, month, day)
}
```

```rust
        harness_id: &str,
        project_id: Option<&str>,
        cwd: Option<&str>,
    ) -> Result<SessionRecord> {
        let hub_session_id = Uuid::new_v4().to_string();
        let started_at = clock::now_rfc3339();

        let mut session = NewSession::new(harness_id, harness_id, LOCAL_TARGET_ID, &started_at)
            .with_cwd(cwd.unwrap_or(""));
        session.hub_session_id = hub_session_id.clone();
        session.cwd = cwd.map(str::to_string);
        session.project_id = project_id.map(str::to_string);

        self.store.insert(&session)?;

        self.store
            .get(&hub_session_id)?
            .ok_or_else(|| crate::error::Error::InvalidInput("刚写入的会话读不回来".to_string()))
    }

    pub fn get(&self, hub_session_id: &str) -> Result<Option<SessionRecord>> {
        self.store.get(hub_session_id)
    }

    pub fn finish(&self, hub_session_id: &str, exit_code: Option<i32>) -> Result<bool> {
        self.store
            .finish(hub_session_id, exit_code, &clock::now_rfc3339())
    }

    pub fn list_recent(&self, limit: u32) -> Result<Vec<SessionRecord>> {
        self.store.list_recent(limit)
    }
}
```

```rust
//! 真实 PTY 后端。只有这个文件依赖 `portable-pty`，其余代码只认 `PtyBackend`。

use std::collections::HashMap;
use std::io::Write;
use std::sync::Mutex;

use portable_pty::{Child, CommandBuilder, MasterPty, PtySize, native_pty_system};

use crate::error::{Error, Result};
use crate::pty::backend::{PtyBackend, PtyCommand};

struct RunningPty {
    master: Box<dyn MasterPty + Send>,
    writer: Box<dyn Write + Send>,
    child: Box<dyn Child + Send + Sync>,
}

#[derive(Default)]
pub struct PortablePtyBackend {
    sessions: Mutex<HashMap<String, RunningPty>>,
}

impl PortablePtyBackend {
    pub fn new() -> Self {
        Self::default()
    }
}

impl PtyBackend for PortablePtyBackend {
    fn spawn(&self, session_id: &str, command: &PtyCommand) -> Result<Option<u32>> {
        let pty_system = native_pty_system();
        let pair = pty_system
            .openpty(PtySize {
                rows: command.rows,
                cols: command.cols,
                pixel_width: 0,
                pixel_height: 0,
            })
            .map_err(|error| Error::InvalidInput(format!("打开 PTY 失败：{error}")))?;

        let mut builder = CommandBuilder::new(&command.program);
        builder.args(&command.args);
        if let Some(cwd) = &command.cwd {
            builder.cwd(cwd);
        }
        for (key, value) in &command.env {
            builder.env(key, value);
        }

        let child = pair
            .slave
            .spawn_command(builder)
            .map_err(|error| Error::InvalidInput(format!("启动进程失败：{error}")))?;
        // slave 端必须在这里丢弃，否则父进程持有的句柄会让子进程永不收到 EOF。
        drop(pair.slave);

        let pid = child.process_id();
        let writer = pair
            .master
            .take_writer()
            .map_err(|error| Error::InvalidInput(format!("获取 PTY writer 失败：{error}")))?;

        self.sessions.lock().map_err(|_| Error::StateLockPoisoned)?.insert(
            session_id.to_string(),
            RunningPty {
                master: pair.master,
                writer,
                child,
            },
        );

        Ok(pid)
    }

    fn write(&self, session_id: &str, bytes: &[u8]) -> Result<()> {
        let mut sessions = self.sessions.lock().map_err(|_| Error::StateLockPoisoned)?;
        let session = sessions
            .get_mut(session_id)
            .ok_or_else(|| Error::InvalidInput(format!("未知会话：{session_id}")))?;
        session
            .writer
            .write_all(bytes)
            .map_err(|error| Error::InvalidInput(format!("写入 PTY 失败：{error}")))?;
        session
            .writer
            .flush()
            .map_err(|error| Error::InvalidInput(format!("刷新 PTY 失败：{error}")))?;
        Ok(())
    }

    fn resize(&self, session_id: &str, cols: u16, rows: u16) -> Result<()> {
        let sessions = self.sessions.lock().map_err(|_| Error::StateLockPoisoned)?;
        let session = sessions
            .get(session_id)
            .ok_or_else(|| Error::InvalidInput(format!("未知会话：{session_id}")))?;
        session
            .master
            .resize(PtySize {
                rows,
                cols,
                pixel_width: 0,
                pixel_height: 0,
            })
            .map_err(|error| Error::InvalidInput(format!("调整 PTY 尺寸失败：{error}")))?;
        Ok(())
    }

    fn kill(&self, session_id: &str) -> Result<()> {
        let mut sessions = self.sessions.lock().map_err(|_| Error::StateLockPoisoned)?;
        let mut session = sessions
            .remove(session_id)
            .ok_or_else(|| Error::InvalidInput(format!("未知会话：{session_id}")))?;
        session
            .child
            .kill()
            .map_err(|error| Error::InvalidInput(format!("结束进程失败：{error}")))?;
        Ok(())
    }

    fn is_running(&self, session_id: &str) -> Result<bool> {
        let mut sessions = self.sessions.lock().map_err(|_| Error::StateLockPoisoned)?;
        let Some(session) = sessions.get_mut(session_id) else {
            return Ok(false);
        };
        Ok(session
            .child
            .try_wait()
            .map_err(|error| Error::InvalidInput(format!("查询进程状态失败：{error}")))?
            .is_none())
    }
}
```
